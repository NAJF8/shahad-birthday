## 🏗️ Architecture (لماذا GitHub-only؟)

هذا المشروع **مقصود أن يكون Static بالكامل** — لا Database، لا Backend خارجي، لا Cloudflare/Firebase/Supabase. الـsource of truth الوحيد هو هذا الـRepository نفسه:

```
Birthday Website (index.html)
        │  يقرأ
        ▼
 data/site.json  ← القيم الافتراضية (مصدر الحقيقة الدائم)
        │
        ▼
 localStorage (في متصفح الزائر/الأدمن)  ← تعديلات مؤقتة محلية فقط
```

- **الموقع العام** (`index.html`) للقراءة فقط دائماً — لا يوجد أي زر فيه يكتب أو يعدّل أي شيء على مستوى الموقع نفسه (نموذج "أضيفي تهنئة" يحفظ في متصفح الزائر فقط، ولا يصل لباقي الزوار).
- **لوحة Admin** (`/admin/`) منفصلة تماماً، بدون أي رابط من الموقع العام إليها، وتحتاج تسجيل دخول.
- أي تعديل تحفظينه من Admin يُخزَّن في `localStorage` **الخاص بمتصفح جهازك فقط** — فوراً، يبقى بعد Refresh وإغلاق المتصفح، لكنه **لا يظهر لزائر آخر من جهاز آخر** لأنه لا يوجد Backend يوزّعه. لجعل تعديل ما دائماً ومرئياً للجميع: اضغطي "تصدير site.json" من لوحة التحكم، ثم استبدلي ملف `data/site.json` بالملف الذي نزل، وارفعيه (commit + push) إلى GitHub.

## 🔐 Security notes

- **لا يوجد Backend حقيقي** في هذا المشروع، وبالتالي **لا يوجد Authentication حقيقي بمعنى الكلمة**. شاشة الدخول في `/admin/` (Username: `mohammed`, Password: `0224`) هي فقط حاجز بسيط من جهة المتصفح (client-side) — موجودة في `admin/app.js` بشكل صريح وواضح، وأي شخص يفتح "Inspect" على الصفحة يمكنه رؤيتها أو تجاوزها.
- هذا الاختيار **مقصود وصريح**: بما أن المشروع GitHub Pages-only بدون خادم، أي "حماية" فعلية (Server-side sessions، HttpOnly cookies) تحتاج Backend لم يُطلب بناؤه هنا. حاجز الدخول يمنع **الدخول العرضي فقط** (شخص يفتح الرابط بالصدفة)، وليس شخصاً يتعمد فحص الكود.
- **لا تشاركي رابط `/admin/` علناً.** لا يوجد ضمن الموقع العام أي رابط أو زر يؤدي إليه.
- تم فحص المشروع بالكامل قبل الرفع بحثاً عن GitHub tokens / API keys / secrets حقيقية — لا يوجد أي منها. ملف `.env.example` موجود فقط للتوضيح أنه لا توجد متغيرات بيئة سرية حقيقية يحتاجها المشروع.
- كل نص يُدخله الزائر (التهنئات) أو الأدمن (الأوصاف) يُعرض عبر `textContent`/HTML-escaping قبل إدراجه في الصفحة لمنع XSS.

## 🚀 طريقة التشغيل محلياً

1. افتح المجلد في الطرفية:
   ```bash
   cd شهد
   ```
2. شغّل خادم محلي بأي أداة مفضلة:
   ```bash
   npx serve .
   # أو بواسطة بايثون:
   python -m http.server 3000
   ```
3. افتح المتصفح على:
   - الموقع الرئيسي: `http://localhost:3000/`
   - لوحة التحكم: `http://localhost:3000/admin/`
