# selected-photos/

ضعي هنا صور شهد الحقيقية (jpg / jpeg / png / webp).

## ملاحظة مهمة وصادقة عن كيفية عمل هذا

هذا الموقع **Static بالكامل** (بدون Backend، بدون خطوة بناء تعمل تلقائياً). المتصفح لا يستطيع "رؤية" ملفات هذا المجلد من تلقاء نفسه — إضافة صورة هنا وحدها **لا تكفي** لتظهر في الموقع، لأن لا يوجد شيء يقرأ محتويات هذا المجلد أثناء فتح الصفحة.

توجد طريقتان فعليتان لإضافة الصور، وكلاهما حقيقي:

### الطريقة الأسهل — لوحة التحكم
افتحي `/admin/` → تبويب "إدارة الصور والمعرض" → ارفعي الصورة مباشرة من جهازك، واختاري قسمها (لحظات جميلة / جدار الصور / Portrait). هذا يعمل فوراً بدون الحاجة لهذا المجلد إطلاقاً.

### الطريقة الثانية — إذا وضعتِ الصور هنا فعلاً
شغّلي هذا الأمر مرة واحدة من جذر المشروع بعد إضافة الصور:

```bash
node scripts/sync-selected-photos.js
```

هذا السكربت يفحص هذا المجلد، ويضيف أي صورة جديدة تلقائياً إلى `data/site.json` (بنوع "لحظات جميلة" افتراضياً، والعنوان من اسم الملف — لن يخترع سنة أو مناسبة أو أي معلومة غير موجودة في اسم الملف). بعدها ارفعي (`git add`, `git commit`, `git push`) ليظهر التغيير على الموقع المباشر للجميع.
